三、使用说明
触发方式
在 智能体 对话中直接用自然语言描述需求即可，包含「企百 / 企业百家号 / 加白 / 白名单」等关键字会命中此 skill。
典型流程
1. 用户描述需求（含功能中文名 + 条目列表）
2. Skill 解析功能中文名 → 白名单 key
3. Skill 解析条目并回显给用户确认
4. 提交加白 → 返回 ticketId + 值班审批人
5. 自动轮询审批结果（最长 30 分钟）

    * APPROVED → 展示新增/跳过数量
    * REJECTED → 返回拒绝原因
    * UNKNOWN → ticketId 无效
    * TIMEOUT → 提示联系值班人，可携 ticketId 稍后再查

不支持的能力
* 白名单查询、删除/下线
* 非企业百家号业务的白名单
